Install in 3 steps (Android)

  1. Download the APK with the button above.
  2. Tap the file when the download finishes (or find it in your Downloads or Files app).
  3. If Android says it's blocked, tap Settings and turn on Install unknown apps (also called Allow from this source) for your browser or Files app, then go back and tap Install.

If Play Protect shows a warning, that's normal for test builds not yet on Google Play; tap More details then Install anyway. When the app reaches Google Play later, uninstall these test versions first, then install from the Play Store.
